# Arbeitsanweisung für Claude Code

Die Regeln für alle stehen in [CONTRIBUTING.md](CONTRIBUTING.md). Schreibe deutsch.

- **Nichts, was Rückschlüsse erlaubt:** keine personenbezogenen Daten, keine Standorte, Städte oder Anschriften, keine echten Berufsschulen, Kammern, Abteilungen, internen Systeme, Rechner- oder Netznamen, keine Hinweise auf interne Entwürfe – auch nicht als Beispiel in Inhalten, Grafiken, Tests, Commits und Pull Requests. Beispiele: „Muster GmbH“, „Musterstadt“, `firma.de`. Im Zweifel nachfragen.
- Branch und Pull Request, nie direkt nach `main`; Pull Requests nur auf ausdrückliche Bitte, der Nutzer mergt.
- Inhalte ändern: `content/meta.json` (Stand) und `content/CHANGELOG.md` mitziehen.
