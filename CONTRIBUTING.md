# Mitwirken

Dieses Repository ist öffentlich.

- **Nichts, was Rückschlüsse erlaubt** auf den Betrieb, in dem die App genutzt wird, oder auf Personen: keine personenbezogenen Daten, keine Standorte oder Anschriften, keine echten Berufsschulen, Kammern oder Abteilungen, keine internen Systeme, Rechner- oder Netznamen, keine Hinweise auf interne Entwürfe oder Absprachen – auch nicht als Beispiel in Inhalten, Grafiken, Tests, Commits oder Pull Requests.
